# Disney Plus Clone

## About 

A mobile responsive ReactJS Disney Plus clone.

## Access the Disney+ clone here: https://disneyplus-clone-2214e.web.app/

## Features 

- Login/Logout using Firebase authentication
- Navigate the Login, home page and movie detail pages
- Carousel image slider
- Autoplay video viewers
- Movie categories including: Recommended for you, New to Disney+, Originals and Trending
